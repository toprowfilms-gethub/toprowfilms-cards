# Top Row Films cards

Production title cards for Top Row Films social posts.

- `make_card.py`: card generator (1080x1350). Optional `--cover` fills the cover-art frame; only use art you made or have permission to use. Without it the frame shows the Top Row Films seat icon; `--art` fills it with generated artwork instead.
- `assets/`: logo and icon.
- `cards/YYYY-MM-DD/`: cards for each day.
